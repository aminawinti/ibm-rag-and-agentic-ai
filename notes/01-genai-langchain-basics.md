# Course 1 - Develop Generative AI Applications: Get Started

## Background note

Coming from a frontend background, this course was my first real hands-on exposure to the LLM-application layer (prompt templates, chains, structured output) rather than just consuming an API from a UI.

## What this course covered

- GenAI + LangChain fundamentals: prompt templates, chains, agents
- Building a small Flask app that returns structured (JSON) output from an LLM
- Comparing different models (Llama, Granite, Mistral) for the same task

## What I actually built

Built a Flask app that integrates IBM watsonx.ai and multiple LLMs (Llama, Granite, Mistral), using LangChain for prompt engineering and structured JSON output parsing. 

See snippets from this app at  `labs/01-genai-langchain-flask.py`
